# lvdonghome

綠動貿易有限公司家居商城演示站，使用 React + Vite 搭建。

## 运行

```bash
npm i
npm run dev
```

后台演示入口：`/#/admin`（本项目当前使用单页状态路由，访问 `/admin` 也会被 Vite 回退到首页；可从页面链接进入后台）。

演示后台账号：`admin@lvdonghome.demo`

演示后台密码：`LvdongDemo2026!`

支付、后台登录和订单管理均为前端演示功能，接入真实服务前需要配置服务端鉴权、订单数据库及 PayPal/银行卡支付网关。公司注册号目前以 Demo-registered 占位，需替换为实际注册号。
